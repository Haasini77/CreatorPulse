# CreatorPulse 📊

### Social Media Content Intelligence & Engagement Prediction

CreatorPulse is a data analytics and machine learning project that analyzes social media engagement and predicts engagement using a Random Forest Regression model. The results are visualized through an interactive Power BI dashboard.

## 🛠️ Tech Stack

- Python
- Pandas
- SQLite
- Scikit-learn
- Random Forest Regression
- Power BI
- Git & GitHub

## 📊 Features

- Social media engagement analysis
- Platform-wise engagement comparison
- Content type and topic analysis
- Posting hour analysis
- Hashtag analysis
- Engagement prediction using Machine Learning
- Actual vs Predicted engagement visualization
